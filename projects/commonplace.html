Commonplace

A mobile commonplace book for saving, organizing, and finding the ideas and references you want to keep.

View on GitHub →

Overview

Commonplace is a mobile app for building a personal reference library across ideas, notes, articles, books, films, music, and more.

I built the core mobile experience with Expo, React Native, and TypeScript. The app brings together a searchable library, type filters, custom item types and tags, item details, and flows to create, edit, and delete entries.

  • Create, edit, and delete saved items with optional details and source links
  • Organize references with built-in or custom item types and tags
  • Search and filter the library, then open items to view their details

Tech Stack

A cross-platform mobile app built with Expo and React Native in TypeScript, using React Navigation for screen flows and AsyncStorage to keep the library on the device.

Expo React Native TypeScript React Navigation AsyncStorage

Motivation

I wanted a more intentional alternative to scattered saves: one place for ideas, notes, articles, books, and other references I might want to return to later. Commonplace is designed as a personal reference library that makes saving and rediscovering useful material easier.

Design Challenge

A personal library needs to support many kinds of material without making every save feel like filling out a form. I designed flexible entries with optional details, custom types, and tags while keeping browsing, search, and item details consistent.

AI-assisted enrichment and rediscovery are longer-term directions. The current focus is the core experience of capturing, organizing, searching, and revisiting saved items.

Next Steps

I’d like to explore AI features that help people make sense of their saved items, such as suggesting tags, summarizing entries, and surfacing connections between related ideas. I also want to add different ways to view and explore the library, including a visual view of how saved ideas relate to one another.
